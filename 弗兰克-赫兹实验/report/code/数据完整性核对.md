## 后续处理边界

- 手写采用V开头的电压符号，指导书和模板采用U；正式转录时说明两者表示同一电压，不改变读数。
- 红框只是峰值定位参考。第一组16.0 V与16.5 V附近电流出现相同读数，
  第二组15.5 V与16.0 V附近也有平顶，不能把红框电压直接当成无歧义的拟合极值。
- 逐差法与最小二乘法使用同类极值序列，不混用峰、谷；具体选峰数及配对方式在计算时说明。
- 与公认值比较时采用本课程指导书第122页给出的11.7 V。
- 指导书规定自动扫描步长为0.2 V、仅作现象观察；补充真实现象描述即可，
  如有示波器照片可用于佐证，不把照片当成必交条件。
