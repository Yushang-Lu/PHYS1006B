# 报告源码与构建

在本实验的 `report/` 目录执行：

```sh
python3 code/build.py
```

最终输出仅为 `report/report.pdf`。原始记录 PDF 的前 3 页直接复制，后接重新排版的
数据处理、结论分析和讨论；原文件中的第 4、5 页空白课后页不再拼入。
正文按内容自然分页，目前完整报告共 5 页。

## 输入与源码

- `../../resource/半导体实验_已填写原始记录.pdf`：用户提供的已填写 PDF 独立副本，
  不覆盖同目录的原空白模板，也不依赖下载目录。
- `measurements.json`：6 个温度、36 组四次换向电压、手写霍尔电压校验值、磁场读数、
  样品厚度及指导书常数；电压保留原始正负号。
- `report.md`：可编辑正文，结果表及数值标记由分析脚本自动填充。
- `analyze.py`：重算霍尔电压、带截距最小二乘拟合、绘图，生成结果和已填充 Markdown，
  并将本文使用的 Markdown 子集转换成排版正文。
- `postlab.tex`：课后页的字体、页眉、页码及自然分页版式。
- `assemble.py`：拼接原始页与课后页，渲染全部成品页面，并逐像素比较前 3 页。
- `build.py`：统一构建入口；所有计算、图片、排版与校验中间文件均在系统临时目录生成，
  退出时自动清理；构建失败不替换已有报告。

正文只支持当前使用的二、三级标题、普通段落、LaTeX 数学、简单表格与独立图片。
表格公式中的竖线须使用 `\lvert`、`\rvert`，避免与 Markdown 分隔符冲突。

## 数据口径

处理方法取自《大学物理实验 B 指导书》实验十三（印刷页 145–154）。
换向顺序按本次记录表的列头，即 `(IM, IS)` 为 `++、-+、--、+-`，
不按指导书示例表重新排列原始列。

实际工作电流为 2.0–4.0 mA，间隔 0.4 mA，不补齐指导书示例的 0.2 mA 间隔。
30℃、2.4 mA 的 `V1=273.65 mV` 以及 30℃的 `B1=591 Gs` 均按原记录保留，
不按相邻点趋势改动。36 组重算霍尔电压与手写值差异均不超过 0.005 mV。

电压拟合使用未舍入的重算霍尔电压；磁场按各温度的正反向读数分别计算。
霍尔系数、灵敏度报告大小；浓度按 `n=1/(e|RH|)` 近似估算。
禁带宽度使用全部六个温度点拟合 `ln(|RH|/(1 m³/C))` 对 `1/T`，
按指导书忽略 `T^(-3/2)` 前因子，最后将焦耳换算为电子伏特。
图中温度倒数显示为 `10^-3 K^-1`，计算中的斜率以 `K` 为单位。
全部计算常数来自 `measurements.json`，修改后须通过统一入口重建。

## 依赖

- `latexmk`、XeLaTeX，及源码使用的 Times New Roman、TeX Gyre Termes Math、
  WPS 汉仪书宋二和汉仪中黑字体。
- conda `tf2` Python：NumPy、Matplotlib。
- Codex Python：`pypdf`、Pillow。
- Poppler：`pdftoppm`。

Python 默认路径与本仓库其他实验一致；可用 `--plot-python`、`--pdf-python`
或环境变量 `PLOT_PYTHON`、`PDF_PYTHON` 替换。仅运行统一入口，不在源码目录直接编译。

## 校验

构建过程检查数据形状及符号，以两种最小二乘实现交叉核对拟合参数，并保存手写数值校验结果。
拼接后逐页渲染，前 3 页与已填写原始 PDF 在 150 dpi 下必须逐像素相同。
需要人工目视检查图表、公式、中文和分页；编译成功不代替目视验收。

需要保留临时验收材料时，可指定报告目录之外的位置：

```sh
python3 code/build.py --qa-dir /tmp/semiconductor-report-qa
```

该目录包含渲染页面、已填充 Markdown、课后 PDF、计算结果、转录校验及页面验证记录。
默认构建不保留这些中间材料。
