# 光的等厚干涉现象与应用报告

在本实验的 `report/` 下运行：

```sh
python3 code/build.py
```

唯一最终 PDF 为 `report/report.pdf`。第 1、2 页直接取自文件名带 `2` 的原始
PDF，保留预习、读数及签字；替换原第 3 页，接入两页课后报告。
所有计算与编译在自动清理的临时目录进行，成功验收后原子替换最终 PDF。

## 输入与处理

- `measurements.json`：第 31—10 环的左右位置读数，单位 mm，以三位小数字符串保留；
  钠光波长 589.30 nm 来自指导书印刷页 29。
- `report.md`：课后报告正文与 LaTeX 公式模板。数值和表格由计算脚本填入，
  同一份已填充 Markdown 生成排版正文。
- `analyze.py`：11 组不重叠配对，级次差 11；计算直径、平方、逐差、平均曲率半径、
  均值的 A 类标准不确定度。用 Decimal 交叉检查平方差，
  再用各组曲率半径的均值和标准误交叉检查传播结果。
- `postlab.tex`：与原 PDF 相同的页面尺寸、左右边距及 10.45 bp 书宋正文，
  标题使用书宋加粗；不在 LaTeX 中重新仿制页眉。数据表平方值保留六位小数作为运算中间量；
  最终不确定度保留两位有效数字，半径与其对齐小数位。
- `assemble.py`：直接提取原第三页的页眉文字及横线矢量指令，在原坐标复用，
  页码使用原模板的汉仪中等线字体、字号和基线。拼接后以 150 dpi 逐像素比较
  前两页、后两页页眉及第三页页码，并比较独立课后 PDF 与拼接 PDF 的后两页。

高分辨率复核原始记录：第 27 环左读数为 25.146 mm，第 22 环右读数为
17.809 mm，第 18 环左读数为 24.412 mm，第 14 环右读数为 18.489 mm。
原值均保留，不按相邻读数趋势调整。劈尖选做表为空，不作该项计算。
不确定度按已确认方案仅报告 A 类标准不确定度，波长按给定常数处理。

## 依赖与验收

- conda `tf2` Python：NumPy；可用 `--calc-python` 或 `CALC_PYTHON` 替换路径。
- 含 `pypdf`、Pillow、ReportLab 的 Python：默认使用 Codex runtime；
  可用 `--pdf-python` 或 `PDF_PYTHON` 替换。
- `latexmk`、XeLaTeX、Poppler 的 `pdftoppm`。
- Times New Roman、TeX Gyre Termes Math，以及源码指定的 WPS
  汉仪书宋二、汉仪中等线字体；页眉保留原 PDF 内嵌字体。

可在报告目录外保留验收材料：

```sh
python3 code/build.py --qa-dir /tmp/newton-rings-report-qa
```

该目录含填充后的 Markdown、计算结果、独立课后 PDF、最终 PDF、渲染图片与
页面验证记录。提交前仍须人工逐页检查中文、数学公式、表格和分页；
逐句审查正文是否仅含必要计算、结论、误差分析及讨论题答案。
修改输入数据或常数后必须重新运行统一构建，不单独编译入口文件。
