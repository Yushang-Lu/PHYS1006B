# 四．实验结论及现象分析

磁阻随磁场变化并具有磁滞，可用于磁场检测、开关、电流测量及磁信息读出；齿轮转动引起的周期信号可用于角位移检测。

主要误差来自电流、电压表的读数分辨率和零点偏差，螺线管有限长度及外界磁场，偏置磁铁位置变化，以及齿轮角度读数和传感器间隙变化。扫描中回调电流会改变磁化历史，应保持单方向调节。

# 五．讨论题

## 1．为什么增加磁场和减小磁场获得的磁阻曲线不重合？

铁磁层具有磁滞，相同外磁场下的磁化状态与先前的磁化过程有关。增、减磁场时各层磁化方向的相对取向不同，自旋相关散射及电阻也不同，因此两条曲线不重合。

## 2．不同磁偏置影响电流测量灵敏度的原因是什么？

固定导线与传感器的距离 $r$，有

$$
B=B_0+\frac{\mu_0 I}{2\pi r},\qquad
\frac{\mathrm{d}U}{\mathrm{d}I}=\frac{\mathrm{d}U}{\mathrm{d}B}\frac{\mu_0}{2\pi r}.
$$

偏置场 $B_0$ 改变传感器的工作点，因而改变局部斜率 $\mathrm{d}U/\mathrm{d}B$。选在线性且斜率较大的区间可提高灵敏度；偏置过低或进入饱和区均不理想，不能仅凭偏置电压较高就断定灵敏度更大。
